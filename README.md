# 冶金企业原材料采购管理系统前端

本项目是“冶金企业原材料采购管理系统”的 Vue 3 单页管理端，面向管理员、采购员、质检员和库管员等角色，提供采购业务和仓储业务的可视化操作入口。

当前已接入真实账号注册、用户名/邮箱登录和 JWT 会话恢复；仪表盘、物料档案、供应商管理和个人中心已具备可用界面，其中物料与供应商页面已连接后端接口。采购计划、采购订单、到货检验、入库、出库、库存和报表入口已完成路由与菜单占位，业务接口将在后续阶段补齐。

## 技术栈

- **Vue 3**：使用 Composition API 与 `<script setup>` 编写单文件组件。
- **Vite 5**：负责开发服务器、`/api` 代理和生产构建。
- **JavaScript**：项目当前不使用 TypeScript，保持轻量的 JavaScript 技术栈。
- **Element Plus**：提供表单、表格、弹窗、分页、标签、消息提示和布局组件；`@element-plus/icons-vue` 提供菜单与操作图标。
- **Vue Router 4**：使用 HTML5 History 路由，统一维护公开页面、登录后页面和未匹配路径跳转。
- **Pinia 2**：保存当前用户、角色、权限和本地 token，负责会话恢复、登录、退出和权限判断。
- **Axios**：在 `src/api/http.js` 中统一封装 `/api` 请求、Bearer Token 注入、超时和 401 会话失效处理。
- **ECharts 5**：仪表盘使用按需引入的柱状图和环形图展示采购数量；其余报表能力待后续接入。

## 当前已实现

- Vite 开发和生产构建配置，默认开发地址为 `http://localhost:5173`。
- Element Plus 全局注册、图标注册和基础样式。
- `MainLayout` 主布局：深色侧边菜单、顶部用户栏、退出登录和响应式窄屏菜单。
- 登录与注册：支持用户名/邮箱登录、账号注册、表单必填/邮箱/密码校验、加载态和后端错误提示。
- 会话管理：Pinia 保存用户与 token；应用启动时调用当前用户接口恢复会话；退出时清除本地状态。
- 路由守卫：`/login`、`/register` 为公开页面，其余路由需要 token；已登录用户访问认证页会回到仪表盘。
- 仪表盘：读取物料档案和采购报表，展示物料总数、启用/停用数量、类别分布、年度采购总量、物料采购排名柱状图和采购构成环形图；支持刷新、加载态、空态和错误态。
- 物料档案：支持关键词查询、分页、列表加载、创建、编辑、删除；维护编码、名称、类别、单位、本年度采购数量和启用/停用状态；采购数量支持非负数及最多两位小数校验。
- 供应商管理：支持关键词查询、分页、创建、编辑、删除；维护供应商编码、名称、联系人、联系电话和启用/停用状态；联系电话支持手机号或常见区号座机格式校验。
- 统一交互样式：管理页搜索按钮带搜索图标，状态使用启用/停用语义化标签，新增/编辑弹窗提供分区表单、校验反馈、保存加载态和移动端适配。
- 个人中心：展示当前账户、邮箱和角色，提供修改密码表单校验及注销当前会话入口。

## 页面规划

系统页面按采购到库存的业务闭环组织：

1. 登录
2. 仪表盘
3. 物料档案
4. 供应商管理
5. 采购计划
6. 采购订单
7. 到货检验
8. 入库管理
9. 领用出库
10. 库存台账
11. 统计报表

已实现页面提供查询、分页、新增、编辑、删除、状态标签、表单校验、加载态、空态和错误态；后续业务页面将沿用同一套管理页交互，并根据用户角色显示可用菜单。

## 请求与路由

- Vite 开发服务器将 `/api` 代理到 `http://localhost:8080`。
- Axios 实例位于 `src/api/http.js`，默认基地址为 `/api`。
- 请求拦截器从 `localStorage.token` 读取令牌，并添加 `Authorization: Bearer <token>`。
- 响应收到 `401` 时会清理本地 token 并跳转登录页。
- 当前路由守卫只检查 token 是否存在，尚未接入真实 JWT 解析和角色权限判断。
- 菜单组件已保留基于角色/权限的过滤入口（`userStore.can`），当前后端返回的角色与权限数据需要进一步联调确认。

## 本地运行

先按同级后端仓库 `../backend/README.md` 准备 MySQL、配置 `DB_URL`/`DB_USERNAME`/`DB_PASSWORD` 并启动 Spring Boot；数据库脚本需先执行 `schema.sql`，再执行 `data.sql`。在后端已监听 `http://localhost:8080` 后，再在 `frontend` 目录执行：

```bash
npm install
npm run dev
```

开发服务器默认地址为 `http://localhost:5173`。

生产构建和预览：

```bash
npm run build
npm run preview
```
